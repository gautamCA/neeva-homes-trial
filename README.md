# Neeva Homes · Private Operations Trial

An interactive browser-only demonstration prepared for Neeva Homes by Silicon Soul.

## What works in this trial

- Fictional sample enquiry management with assignment, priority and activity history
- Automatic round-robin routing when enabled for new trial enquiries
- Contact outcomes, notes, follow-ups and consultation scheduling
- On-demand checks for untouched leads, due actions and proposals missing a next step
- Consultation completion, automatic proposal draft handoff, editable proposal tracking and Won progression
- Owner reports and a downloadable sample CSV
- WhatsApp message preview and copy (does not send a message)
- Browser-local state persistence and reset

## Important boundaries

This is not a connected Neeva Homes production service. No real customer data, background automation, WhatsApp delivery, shared team synchronization, live integrations or actual proposals are transmitted. Trial changes are stored only in the visitor's browser. Production scope, integrations, access control, pricing and rollout need separate agreement.
